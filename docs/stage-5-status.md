outbox 保留原采集编号与时间。只有对应记录返回 saved/duplicate 且有有效数据库 ID 才保存成功回执；invalid/conflict 保留待处理并返回失败退出码。断线重传原请求，不重新采集来替代失败请求，HTTP 200 本身不代表成功。

滚动页根据可见名次重新计算行位置，要求至少三条连续完整行及合法间距。翻页必须有重叠名次并包含下一个目标，重叠行的积分、胜场和辅助昵称必须一致；不能按滑动距离猜名次。返回资料后还会核对名次集合及位置。页面变化或未知值时停止，不完整运行禁止上传。

一轮结束停在最后采集位置，下轮需手动回到榜首。后续仍需实现自动回榜首、弹窗恢复、周期调度，并测量多轮稳定性、内存与 CPU；当前没有后台循环。十人试采不是独立准确率验收。

## 已实现的校验

- 每次截图与点击前验证游戏前台包名；截图分辨率不符就停止。同一设备使用进程锁，防止并发点击。
- 每行重新取得榜单截图并识别式神、表头、积分、胜场及辅助昵称；首页名次区域与已确认参考图比较，不能把旧坐标直接套用到翻页后。
- 点击头像后定位明确的 `ID:数字` 标签，根据标签位置动态定位段位和按钮。第三名以下弹窗会向下移动，已覆盖当前首页的三种位置。
- ID 保留前导零。`名士五段198席` 归到名士组 9，不误归为五段组 5。席位、小段显示保留在 OCR 证据，不新增数据库字段。
- 两张独立资料截图必须解析到同一 ID 和段位。无法识别时有限重试；识别为不同的有效身份时立即停止。头像饰品动画曾使“大名士”误读为“太名士”，未知词仍拒绝，不自动替换。
- 返回后核对原式神、榜单数字、完整昵称 OCR 和静态内容像素差；排除头像与昵称旁饰品的动画区域。昵称仅用于辅助一致性判断，不用作玩家主键。
- ID、段位、积分和胜场维持 0.95 置信度门槛；辅助昵称用 0.85 并排除极小装饰检测框。资料时间差超过 30 秒、重复玩家、榜单变化或未知页面均停止，保存已取得证据；尚不自动跳过或恢复未知页面。
- 一轮复用一个本地轻量 PaddleOCR 实例，CPU 推理线程为 2。该设置不限制模拟器和游戏的 CPU 使用量。
