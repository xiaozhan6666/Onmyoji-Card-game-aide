# 前端首版（2026-10-13）

已按用户要求暂停全式神采集，优先完成 Vue 前端。本地地址 `http://127.0.0.1:5173/`，运行方式见 `frontend/README.md`。

实现总览、式神图鉴、详情、采集概览和统计说明；支持名称搜索、六段位筛选、观察状态筛选、数据刷新、断线重试及移动端导航。采用纸色、墨绿、朱红和中文衬线标题，使用本机已取得的三位式神截图作为头像。

Java 统计接口新增聚合字段，无数据库结构变更：

| 字段 | 含义 |
| --- | --- |
| observation_count | 当前赛季、当前统计窗口内的快照条数，十进制字符串 |
| observed_players | 同一式神内去重的已观察玩家数，十进制字符串 |
| latest_capture_at | 窗口内最新实际采集时间，UTC ISO 8601 或 null |
| latest_observed_grades | 每位已观察玩家最近段位的分布，grade 整数、player_count 字符串 |

观察覆盖与参与有效统计的玩家数分开展示，首次基线不产生胜率。显示时区固定 Asia/Shanghai。BIGINT 计数用 BigInt 格式化，胜率只格式化后端小数字符串，不在前端重新计算权威统计。

验证：前端 TypeScript 检查和生产构建通过；4 项单元测试与 3 项真实浏览器流程通过；后端 39 项单元测试、27 项真实 MySQL 集成测试通过，共 66 项。新增后端测试覆盖基线与有效对局的区别、同一玩家最近段位、跨赛季排除、窗口过期。开发库十条基线保留。

内嵌浏览器自动控制工具无法初始化，因此改用本机 Edge 无头浏览器执行页面验证并保存桌面、手机与详情截图，已人工查看。Codex 浏览器面板已提交打开请求（queued）；本地 URL 可直接在浏览器访问。

尚未实现：管理者登录、单条玩家快照浏览/人工修正、卡组攻略、后台采集开关、自动循环与公网部署。前端不会操作游戏。
